# Monitor Dimmer

A small tray app for Windows 10/11 that controls the brightness of every monitor from one place:
real hardware brightness over DDC/CI, plus a software "extra dim" overlay for screens that don't
support it (TVs, laptop panels, some docks).

## Download

**[⬇ Download MonitorDimmer.exe](https://github.com/ardacanbakis/monitorDimmer/releases/latest/download/MonitorDimmer.exe)**
(always the newest version), then run it. No installer and no .NET needed. Put it anywhere you like
(for example `%LOCALAPPDATA%\Programs\MonitorDimmer`) before turning on *Start with Windows*.
Release notes and older versions are on the [Releases](https://github.com/ardacanbakis/monitorDimmer/releases) page.

- Windows may say *"Windows protected your PC"* because the exe isn't code-signed.
  Click **More info → Run anyway**.
- [`MonitorDimmer-small-needs-dotnet8.exe`](https://github.com/ardacanbakis/monitorDimmer/releases/latest/download/MonitorDimmer-small-needs-dotnet8.exe) is the same app at under 1 MB, if you already have the
  [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0).
- Settings are stored in `%LOCALAPPDATA%\MonitorDimmer.Claude\settings.json`.

## Features

- **Per-monitor cards**: each display has its own brightness (DDC/CI) and extra-dim sliders.
- **All displays**: one card moves every *synced* display; toggle sync per monitor (link icon).
- **Rename in place**: click the pencil (or double-click the name). Enter saves, Esc cancels,
  empty resets. Names are tied to Windows' stable monitor device path, not `\\.\DISPLAYn`.
- **Identify**: shows a big number and name on every screen.
- **Real monitor names** (e.g. "DELL U2720Q") instead of "Generic PnP Monitor".
- **Tray**: left-click toggles the window; right-click has presets, "Turn off extra dim",
  Identify, Settings and Exit. Closing the window hides it to the tray.
- **Single instance**: launching again brings the running window forward.
- **Shortcuts**: Ctrl+Alt+Page Up / Page Down changes brightness of synced displays, with an OSD.
- **Presets**, extra dim remembered across restarts, non-blocking DDC/CI writes,
  auto refresh on display changes and resume from sleep.
- Windows 11 look: accent colour, dark mode, per-monitor DPI, 10 languages.
- **About**: version, links and a donation button (Settings → About, the ♡ button, or the tray menu).

## Monitor support

Hardware brightness needs **DDC/CI** enabled in the monitor's on-screen menu. TVs, some docks,
USB/wireless displays and laptop panels usually don't expose it; use **Extra dim** for those.

## Build from source

Needs the [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```powershell
dotnet build -c Release -o build
.\build\MonitorDimmer.exe
```

Standalone single-file exe (what the releases ship):

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=none -o dist/standalone
```

`app.ico` is generated by the app itself (`MonitorDimmer.exe --export-icon app.ico`);
`--selftest out.txt` validates the translation table.

## Releasing

Releases are built by GitHub Actions ([`.github/workflows/release.yml`](.github/workflows/release.yml)).
Push a version tag and the workflow builds both exes and publishes the release:

```powershell
git tag v2.0.1
git push origin v2.0.1
```
